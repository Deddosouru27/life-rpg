# DESIGN QA — результаты чеклиста

Дата: 2026-08-16 · вьюпорт 390×844 (iPhone 14) · Chromium, `device_scale_factor=2`
Проверка автоматизирована: `scripts/` не содержит её — скрипт разовый, запускался из
временной папки. Ниже — фактические измерения, не намерения.

Что измерялось программно на каждом экране:

- фактически применённое семейство шрифта у заголовка;
- `position` и координаты нижней навигации;
- наличие предков с `filter` / `transform` / `backdrop-filter`, ломающих `position: fixed`;
- размер каждой интерактивной зоны (`button`, `a`, `input`, `[role=switch]`);
- контраст каждой уникальной пары «цвет текста × фактический фон предка» по WCAG 2.1;
- контраст иконок против их фона (порог 3:1 для графики);
- доля площади, залитой акцентным цветом;
- эмодзи в текстовых узлах вне контейнера `.user-glyph`;
- горизонтальный скролл;
- ошибки консоли и необработанные исключения.

## Замечание о методе

Пункты 1, 2 и 9 объясняют, почему первая версия была отклонена: **все три невидимы
при чтении кода.** `position: fixed` в CSS присутствовал и выглядел корректным; шрифт
был подключён и объявлен в `font-family`; буквица описывалась в документе как удачный
приём. Дефект каждого проявлялся только в отрисованном виде.

Отсюда правило для дальнейшей работы: изменение вёрстки не считается завершённым,
пока не открыто в мобильном вьюпорте и не измерено.
